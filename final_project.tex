\section{Overview}
My final project proposal is to create a Python AST to LLVM MLIR IR Object
pipeline. The idea is to leverage the library `mlir-hs`, which consists of
API calls to create MLIR IR objects.
Reference:
https://github.com/google/mlir-hs

\section{Motivation}
Motivations for this kind of an endeavor are grounded in the following:
1. Using Haskell to reason about Python AST objects allows us to leverage
Haskell's early type safety, complex logic expressivity, and reliability to
directly compile Python code.
2. We can directly work with Python AST nodes, rather than having to go through
CPython/other LLVM workflows. Some benefits of this: Note we can operate directly on
annotations and library calls.
